Endpoints

The FastAPI orchestrator exposes an OpenAI-flavored streaming API. The base URL is the chat host (this page); paths are under /api/*. Session IDs live in the browser only — the backend never lists them.

GET/api/models

List available models and the default.

curl ${BASE}/api/models

POST/api/chat?session_id=&model=

Streaming chat completion. Returns text/event-stream with delta frames per token and a closing [DONE]. model defaults to qwen. 

curl -N ${BASE}/api/chat?session_id=${SESSION}&model=qwen \
  -H 'Content-Type: application/json' \
  -d '{"message":"hello in 3 words"}'
data: {"event": "meta", "model": "qwen", "session_id": "${SESSION}"}
data: {"event": "delta", "content": "Hi"}
data: {"event": "delta", "content": " there"}
data: [DONE]
import httpx, json
with httpx.stream("POST", "${BASE}/api/chat",
    params={"session_id": "demo", "model": "qwen"},
    json={"message": "list 3 K8s benefits"},
    timeout=120,
) as r:
    for line in r.iter_lines():
        if not line.startswith("data: "): continue
        payload = line[6:]
        if payload == "[DONE]": break
        obj = json.loads(payload)
        if obj.get("event") == "delta":
            print(obj["content"], end="", flush=True)

GET/api/history?session_id=

Full conversation history for a session (Redis, 24 h TTL).

curl ${BASE}/api/history?session_id=${SESSION}

GET/api/sessions

List every active session in Redis (id + turn count + TTL). Inspection-only — no auth, intentional for the demo. In production this would be admin-gated. 

curl ${BASE}/api/sessions | python3 -m json.tool

POST/api/reset?session_id=

Clear history for a session.

curl -X POST ${BASE}/api/reset?session_id=${SESSION}

GET/api/host-info

CPU model + inference target. Read from /proc/cpuinfo at request time.

curl ${BASE}/api/host-info

GET/api/health

Liveness + Redis reachability.

curl ${BASE}/api/health
